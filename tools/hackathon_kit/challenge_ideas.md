# Challenge Ideas

## Track A: Tokens

- Build a deterministic token launch flow (deploy + mint + transfer + supply verification).

## Track B: NFTs

- Build an NFT mint and ownership query flow with deterministic metadata.

## Track C: Stablecoin rails (STABLE118)

- Demonstrate mint/burn with invariant checks and replay safety.

## Track D: AMMs (AMM119)

- Deploy an AMM pool, add liquidity, and perform a swap with deterministic reserves.

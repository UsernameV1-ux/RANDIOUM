# Moonrand Hackathon Kit

This folder contains a self-contained kit for running a Moonrand hackathon.

## Contents

- `challenge_ideas.md` challenge tracks and prompts.
- `judging_criteria.md` suggested scoring rubric.
- `quickstart_devnet.md` deterministic local devnet instructions.
- `samples/` sample projects with minimal configs, CLI steps, and expected outputs.

## Determinism

All sample flows are designed to run locally without live servers.
Use deterministic CLI commands and avoid wall-clock timestamps in outputs.
